# Task E: Dの実データを踏まえた6鉱物の実装指示

2026-09-14。Dの公開経路をレビュー・マージした後、以下を鉱物ごとのPRで進める。
この文書の追加は6鉱物の一括実装・公開ではない。

## Dから確定した設計

1. 鉱山・貿易・段階別に公開可否を分ける。Raw取得完了は公開承認ではない。
   天然黒鉛は鉱山8年分を公開し、貿易は全年度保留という結果になった。
2. 共通利用はarchive、strict normalizer、entity registry、HHI演算、ステージングと
   失敗時の保全に限定する。リチウムの価格・国・含有率・ミラー置換を他鉱物へ継承しない。
   `process_trade.py` の汎用レジストリ化は、複数の実装で同じ手続きを確認してから行う。
3. 公開スキーマは既存の `production` / `trade` と `available` を保持する。
   別に `publishable` と `publication_status: under_review` を記録できる。
   未公開ブロックに `latest` やHHIを埋めない。監査の数値は別ディレクトリに留める。
4. `verification_status` の既存5値を守る。元資料の推計区分、照合による検証状態、
   公開許可は異なる概念。`not_applicable` は確定値や世界全体の完全性を意味しない。
5. 系列キーと物量単位を明示する。天然黒鉛は `mine_natural_graphite_t` と
   `t natural graphite`。リチウムの既存キーの改名や再計算はこの作業に含めない。
   `classification` は鉱物の実装で定義し、消費側への写像が必要な場合は別PRで追加する。
6. 固定版の年次系列と同一版による過去改訂系列を区別する。年度・推計・丸め残差を保持。
   YoYフラグを理由付きでレビューし、系列の途中に新しい版・2025年を自動挿入しない。

## 鉱物ごとの着手範囲

HSコードは現行catalogの互換性基準であり、新たな分類検証・公開承認ではない。
各PRの着手時に対象年のHS版と一次資料の表頭・脚注を確認する。

| 順番 | 鉱物 | 現行headline HS | 初回PRの範囲・判断事項 |
|---|---|---|---|
| E1 | マンガン | 260200 | 既存監査・過去原本を再利用。含有Mn、貨物重量、湿量／乾量、持分、会計年度を保持。空の人間レビュー台帳を自動承認で埋めない。まず鉱山の公開可否、次に貿易を別判定。 |
| E2 | コバルト | 260500, 810520 | 原鉱段階と後段の測定対象を確認し、個別系列で監査。コードをまたぐ重量合算・金属含有量への換算は原資料と係数レビューまで保留。 |
| E3 | ニッケル | 260400, 750210, 750220 | 3コードを別段階で取得し、地金等の物量と鉱山の測定単位を照合。リチウムの価格アンカーを持ち込まない。 |

各鉱物で、(a) 定義・対象年・原本取得と再生、(b) 原数値のレビューと測定対象・国母集団の確定、
(c) 差異の根拠調査・採用判断、(d) 段階別公開判定とページ出力を順に完了する。
鉱物単位でも大きくなる場合はこの順にPRを分割する。未解決項目がある段階は公開保留を許容し、
公開可能な別段階と一緒に強制保留したり、公開できる段階に合わせて承認したりしない。

## B・C・Fとの受け渡し

- B: 天然黒鉛2017〜2024の原本取得を重複しない。新版や過去改訂は新しいvintageとして渡す。
  黒鉛のダイジェストと固定版を黙って更新しない。マンガンも既存過去版の取得記録を確認する。
- C: 2025年追加は鉱物・段階ごとにクエリ完了、欠測、推計、比較可能性を報告する。
  グローバルなend_year変更だけで黒鉛の固定公開系列を延長しない。
- F: `available: false` + `publication_status: under_review` は「確認中」を日英で表示する。
  ゼロ値や「取得すれば出る」という表示に置き換えない。出典リンクは鉱山／貿易状態用も扱う。
  チャートを公開数値のない貿易ブロックに生成しない。

出力契約に変更が必要なら、先にPR内でフィールド・単位・系列キー・既存値への影響を記録し、
B/C/F担当へ渡せる状態にする。このタスクから他担当へのメッセージ送信は行っていない。

## 各PRの完了条件

- Rawハッシュ検証とオフライン再生で同じ原数値・HHI/CR3を再現する。
- 公開候補の年／HS／方向、国母集団、未解決件数、カバレッジ分母、推計区分を記録する。
- 採用理由に対応する原本・範囲・判断を固定し、未レビューの改訂で公開を上書きしない。
- 非対象鉱物の公開JSON、HHI/CR3、既存系列キー・単位が不変であることを確認する。
- 既存と追加の回帰テスト、再レンダリングstaleチェックを通す。
- 失敗時保全と冪等性を確認する。実データと想定の食い違い、残る公開保留をPRに明記する。
- 1件ずつマージ可能なPRを作り、マージ後のmainを次の基点にする。

詳細な共通化候補の旧棚卸しは `mineral-specific-literals-2026-09-14.md` を参照。
そこにある「黒鉛へそのまま適用する」前提の汎用化提案より、上記Dの実測結果を優先する。
