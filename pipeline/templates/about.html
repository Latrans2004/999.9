999.9/About

About

999.9

A hobby project. Public data goes in, one number per material per year comes out, and a scheduled job keeps it current without anyone touching a spreadsheet.

The name

999.9 is the hallmark for the highest commercial purity of a precious metal — four nines, 99.99%. It is the last figure before a claim stops being verifiable, which seemed like a reasonable thing to name a site about published numbers after.

Why concentration

Most discussion of critical minerals runs on adjectives. A supply chain is "fragile", a dependency is "worrying", a country is "dominant". Those words are doing real work, but they are not comparable across materials and they do not change when the underlying facts do.

A concentration index is comparable and it does move. It lets you put natural graphite next to copper on the same axis and see the difference immediately, and it lets you ask whether a supply chain is getting narrower or wider over a decade rather than arguing about whether it is narrow.

It is not a complete picture — the methodology page is explicit about what it misses — but it is a floor to argue up from.

How it is built

A Python pipeline fetches from USGS and UN Comtrade, computes the indices and writes JSON. A renderer turns that JSON into static pages. GitHub Actions runs both on a schedule and commits the result, and GitHub Pages serves it. There is no server, no database and no build step beyond Python, which is the point: it should still work untouched in three years.

The site is structured so that critical minerals is one section rather than the whole site. A second material family needs a catalog file and a fetch adapter, not a rewrite.

Corrections

If a figure here is wrong, the pipeline is wrong, and that is worth knowing. The repository takes issues, and every page's underlying JSON is in the same repository under critical-minerals/data/ if you would rather check the arithmetic yourself.

Credit and disclaimer

Production data is from the US Geological Survey, National Minerals Information Center. Trade data is from UN Comtrade. Both are public and both are excellent; the calculations, choices and any errors on this site are mine alone, and neither organisation endorses or is associated with it.
